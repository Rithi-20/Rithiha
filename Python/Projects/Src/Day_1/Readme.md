# Nova University - Python Fundamentals

## Project Description

This project is part of the Nova University Day 1 Python Practice Activity.

The purpose of this activity is to practice the basic concepts of Python programming before developing larger applications. The activities focus on Python installation, environment verification, syntax, indentation, variables, operators, and type casting.

## Topics Covered

* Python installation
* Python version verification
* Virtual environments
* Python syntax
* Indentation
* Variables
* Data types
* Operators
* Type casting
* Basic student profile program

```bash
python --version
```

## Virtual Environment

A virtual environment provides an isolated environment for a Python project. It helps keep project-specific packages separate from packages used by other Python projects.

### Create Virtual Environment

```bash
python -m venv myenv
```

### Activate Virtual Environment

For Windows:

```bash
myenv\Scripts\activate
```

### File Descriptions

**task_01_installation.py**

Used for Python installation and environment verification practice.

**task_02_variables.py**

Demonstrates Python syntax, meaningful variable names, student information, `print()`, and indentation.

**task_03_operators.py**

Demonstrates arithmetic, comparison, logical, and assignment operators.

**task_04_type_casting.py**

Demonstrates converting values from strings into appropriate data types using type casting.

**task_05_student_profile.py**

Combines the concepts learned in the previous tasks into a basic Nova University student profile program.

## How to Run the Programs

Open the project folder in VS Code and open the terminal.

If the virtual environment has not been activated, activate it using:

```bash
venv\Scripts\activate
```

Run each Python file using:

```bash
python task_01_installation.py
```


