# Nova University Student Service Portal

## Business Purpose

A console-based application that allows students to
perform common academic checks and select their department.

## Features

- Student identification
- Input validation
- Examination eligibility check
- Result check
- Grade calculation
- Department selection
- Repeated services
- Exit option
- Invalid input handling

## Business Rules

Attendance:
- 0 to 100 is valid
- 75 or above = Eligible
- Below 75 = Not eligible

Marks:
- 0 to 100 is valid
- 40 or above = Pass
- Below 40 = Fail

Grades:
- 90–100 = A
- 80–89 = B
- 70–79 = C
- 60–69 = D
- 50–59 = E
- Below 50 = F

## Control Flow Used

- if / elif / else
- while loop
- match
- break
- continue
